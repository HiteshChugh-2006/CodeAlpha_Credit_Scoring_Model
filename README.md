# Credit Scoring Prediction System

## Overview

This project predicts customer creditworthiness using Machine Learning. It compares Logistic Regression, Random Forest, and XGBoost models and selects the best-performing model based on ROC-AUC score.

## Features

* Automated Data Preprocessing
* Feature Engineering
* Model Comparison
* Credit Risk Prediction
* Interactive Streamlit Dashboard
* Performance Visualization

## Technologies Used

* Python
* Scikit-Learn
* XGBoost
* Pandas
* NumPy
* Streamlit
* Matplotlib
* Seaborn

## Model Performance

* Accuracy: 78.5%
* Precision: 71.8%
* Recall: 46.7%
* F1 Score: 56.6%
* ROC-AUC: 80.47%

## Run Locally

Install dependencies:

pip install -r requirements.txt

Train model:

python main.py

Launch dashboard:

streamlit run app.py
